# Agent Instructions

- Skip CI checks for now; use local validation.
- Tell the user what is next for each run and explain options in detail when choices exist.
- Do not edit generated files that include a `generated` header.
- Always give recommendations when there are options.
- After opening or updating a GitHub PR, start a subagent to review the code against repo rules and relevant skills.
- Track meaningful work in GitHub Issues and keep the issue body, canonical plan, and PR body aligned.
